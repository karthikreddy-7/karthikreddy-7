### 🧠 What I do

I work in **Global Markets IT (Prime Brokerage)** at **Nomura**, on the systems behind **regulatory
reporting, client reporting, trade reconciliation and enterprise integration**. The work is Java at
the point where correctness and throughput both matter:

- ⚡ **Regulatory trade persistence microservice** handling **60M+ trade records** — cut insertion
  latency from **3 s → 40 ms** through batching, transaction management and direct JPA persistence.
- 🛡️ **SME for 4+ business-critical Java and Apache Camel adapters** across workflows — production
  support, incident triage, debugging, releases and deployments. The pager is mine.
- 🚪 **Reusable integration gateway framework** built on the **Template Design Pattern**: configurable
  routing, transformations, centralised exception handling, Grafana metrics and health checks.
  Benchmarked at **462 HTTP messages/sec** and adopted across multiple downstream services.
- ☁️ **AWS vendor-feed integration** — Java and Camel adapters polling **SQS** over HTTP and pulling
  files straight from **S3**, with validation gates before anything reaches downstream systems.
- 🐍 **Python automation framework** over the **Jira** and **GitLab** APIs — automated dependency
  upgrades, multi-repository code changes, commits and Merge Requests across **20+ Spring Boot
  microservices**.

### 🏗️ The AI work came out of the backend work

I built **Sonar AutoFix** — an LLM-powered CI/CD remediation platform using Dockerized GitLab
Runners, LLM workflows and Javalang parsers to read SonarQube findings, generate fixes and raise
Merge Requests for developer review. It went into production, cleared **~40% of our SonarQube issues**
across enterprise microservices, and won a **Nomura Star quarterly recognition award**.

> That is the shape of how I work with AI: pointed at a real engineering problem, shipped behind
> review, measured. The projects below are the same instinct, in public.
